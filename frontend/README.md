# APEX Frontend

The frontend is the React dashboard for APEX.

```powershell
pnpm install
pnpm dev
```

Create `.env` from `.env.example`. For local work, use:

```env
VITE_API_BASE_URL=http://localhost:3000/api/v1
VITE_WS_URL=ws://localhost:3000
```

See the main [frontend documentation](../docs/README.md).
